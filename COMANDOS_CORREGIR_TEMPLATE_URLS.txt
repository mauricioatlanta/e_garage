===========================================
CORREGIR URLs EN EL TEMPLATE
===========================================

PROBLEMA:
---------
El template usa: {% country_url 'vehiculos:modelos_por_marca_api' %}
Pero construye: usa:taller:vehiculos:modelos_por_marca_api
La URL correcta es: usa:vehiculos:modelos_por_marca_api

SOLUCIÓN:
---------

cd /home/atlantareciclajes/apps/egarage/current
workon venv_egarage310

# Editar el template para usar app_namespace="direct"
# Esto evita que agregue "taller:" en el medio

# Opción 1: Usar sed para reemplazar (rápido)
sed -i "s/{% country_url 'vehiculos:modelos_por_marca_api' %}/{% country_url 'vehiculos:modelos_por_marca_api' app_namespace='direct' %}/g" \
   taller/templates/taller/us/en/vehiculos/crear_vehiculo.html

# Verificar que se cambió
grep -n "modelos_por_marca_api" taller/templates/taller/us/en/vehiculos/crear_vehiculo.html

# Opción 2: Si sed no funciona, editar manualmente con nano
# nano taller/templates/taller/us/en/vehiculos/crear_vehiculo.html
# Buscar línea 830 y cambiar:
#   {% country_url 'vehiculos:modelos_por_marca_api' %}
# Por:
#   {% country_url 'vehiculos:modelos_por_marca_api' app_namespace='direct' %}

# Verificar que todas las URLs de vehiculos usen app_namespace='direct'
grep -n "country_url 'vehiculos:" taller/templates/taller/us/en/vehiculos/crear_vehiculo.html

# Si hay más URLs que necesitan corrección, corregirlas también:
sed -i "s/{% country_url 'vehiculos:\([^']*\)' %}/{% country_url 'vehiculos:\1' app_namespace='direct' %}/g" \
   taller/templates/taller/us/en/vehiculos/crear_vehiculo.html

# Verificar cambios
