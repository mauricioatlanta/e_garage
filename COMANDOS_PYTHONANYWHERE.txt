COMANDOS PARA PYTHONANYWHERE - RESOLVER CONFLICTO Y ACTUALIZAR
=============================================================

Ejecuta estos comandos EN ORDEN en PythonAnywhere:

1. IR AL PROYECTO:
   cd ~/apps/egarage/current
   workon venv_egarage310

2. RESOLVER CONFLICTO (descartar cambios locales):
   git checkout -- taller/migrations/0011_improve_empresa_model_robust.py

3. ACTUALIZAR CÓDIGO:
   git pull origin main

4. CREAR MIGRACIONES NUEVAS:
   python manage.py makemigrations

5. APLICAR MIGRACIONES:
   python manage.py migrate

6. FORZAR ACTUALIZACIÓN DEL TEMPLATE:
   git checkout HEAD -- templates/taller/reportes/reportes.html

7. LIMPIAR CACHE DE DJANGO:
   python manage.py shell -c "from django.core.cache import cache; cache.clear()"

8. LIMPIAR CACHE DE PYTHON:
   find . -type f -name "*.pyc" -delete
   find . -type d -name "__pycache__" -exec rm -r {} + 2>/dev/null

9. RECOLECTAR ESTÁTICOS:
   python manage.py collectstatic --noinput

10. REINICIAR SERVIDOR (PythonAnywhere):
    touch /var/www/atlantareciclajes_pythonanywhere_com_wsgi.py
