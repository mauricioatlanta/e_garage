  COMANDO PARA RESTAURAR views.py DESDE GIT
═══════════════════════════════════════════════════════════════

Este comando restaura el archivo completo desde origin/main,
lo cual debería solucionar el problema definitivamente:

───────────────────────────────────────────────────────────────
cd /home/atlantareciclajes/apps/egarage/current && \
cp taller/documentos/views.py taller/documentos/views.py.backup_antes_git_$(date +%Y%m%d_%H%M%S) && \
git checkout origin/main -- taller/documentos/views.py && \
python3 -m py_compile taller/documentos/views.py && \
echo "✅ Sintaxis válida" && \
touch /var/www/www_egarage_cl_wsgi.py && \
echo "✅ Servidor reiniciado"
───────────────────────────────────────────────────────────────

Alternativamente, si el comando anterior no funciona, puedes
usar este comando más directo que muestra el contenido desde
Git y lo guarda directamente:

───────────────────────────────────────────────────────────────
cd /home/atlantareciclajes/apps/egarage/current && \
cp taller/documentos/views.py taller/documentos/views.py.backup && \
git show origin/main:taller/documentos/views.py > taller/documentos/views.py && \
python3 -m py_compile taller/documentos/views.py && \
touch /var/www/www_egarage_cl_wsgi.py
───────────────────────────────────────────────────────────────
