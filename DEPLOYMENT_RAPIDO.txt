📋 PASOS RÁPIDOS:

1. SUBIR ARCHIVOS AL SERVIDOR
   ────────────────────────────
   Opción A: Git (recomendado)
   • En tu PC: git push origin main
   • En servidor: el script hará git pull automáticamente
   
   Opción B: Manual (SCP/FileZilla)
   • Subir carpetas: taller/, templates/, gestion_taller/
   • Mantener estructura de carpetas

2. EN EL SERVIDOR (SSH)
   ────────────────────
   cd /ruta/a/egarage
   chmod +x scripts/deploy_seguro_suscriptores.sh
   ./scripts/deploy_seguro_suscriptores.sh

3. EL SCRIPT HARÁ:
   ✅ Backup completo de base de datos
   ✅ Verificación de datos actuales
   ✅ Actualización de código
   ✅ Actualización de dependencias
   ✅ Migraciones (SIN borrar datos)
   ✅ Verificación de que datos se preservaron
   ✅ Archivos estáticos actualizados

4. VERIFICAR
   ──────────
   • El script mostrará conteos de usuarios/empresas
   • Probar login con cuenta existente
   • Verificar que el sitio funciona

🆘 SI ALGO FALLA:
   ──────────────
   Restaurar desde backup:
   cp backups/deployments/db_backup_YYYYMMDD_HHMMSS.sqlite3 db.sqlite3

📦 BACKUPS:
   ────────
   Se guardan en: backups/deployments/

   • db_backup_YYYYMMDD_HHMMSS.sqlite3

✅ PRESERVA:
