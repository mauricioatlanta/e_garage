═══════════════════════════════════════════════════════════════
  SOLUCIÓN: TEMPLATE INDEPENDIENTE (Sin "E-GA" gigante)
═══════════════════════════════════════════════════════════════

Si ves "E-GA" gigante y tarjetas desproporcionadas, es porque el template
está extendiendo una base o CSS global lo está afectando.

Ejecuta este comando para hacer el template completamente independiente:

cd /home/atlantareciclajes/apps/egarage/current && \
cp templates/public/selector_pais.html templates/public/selector_pais.html.backup_independiente_$(date +%Y%m%d_%H%M%S) && \
python3 << 'PYEOF'
import re

file_path = "templates/public/selector_pais.html"

with open(file_path, 'r', encoding='utf-8') as f:
    content = f.read()

# Eliminar cualquier {% extends %} o {% block %}
if '{% extends' in content:
    lines = content.splitlines(keepends=True)
    new_lines = []
    skip_until_endblock = False
    
    for line in lines:
        if '{% extends' in line:
            continue
        if '{% block' in line:
            skip_until_endblock = True
            continue
        if '{% endblock' in line:
            skip_until_endblock = False
            continue
        if not skip_until_endblock:
            new_lines.append(line)
    
    content = ''.join(new_lines)
    print("✅ Eliminadas líneas de extends/blocks")

# Asegurar reset CSS completo
if '<style>' in content:
    style_start = content.find('<style>')
    style_content = content[style_start+7:]
    
    if 'html, body {' not in style_content[:300]:
        reset_css = """    /* Reset completo para aislar de CSS global */
    * {
      margin: 0;
      padding: 0;
      box-sizing: border-box;
    }
    
    html, body {
      width: 100%;
      height: 100%;
      margin: 0;
      padding: 0;
      overflow: hidden;
    }
    
    """
        content = content[:style_start+7] + reset_css + style_content
        print("✅ Reset CSS agregado")

with open(file_path, 'w', encoding='utf-8') as f:
    f.write(content)

print("✅ Template hecho independiente")
PYEOF

touch /var/www/www_egarage_cl_wsgi.py && \
echo "✅ Servidor reiniciado"
