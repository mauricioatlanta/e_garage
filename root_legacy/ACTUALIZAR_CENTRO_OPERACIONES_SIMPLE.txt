OPCIÓN 2: Si NO tienes Git, copia el archivo manualmente

1. Copia el contenido del archivo local:
   templates/taller/cl/es/dashboard/centro_operaciones.html

2. En el servidor, ejecuta:
   cd /home/atlantareciclajes/apps/egarage/current && \
   nano templates/taller/cl/es/dashboard/centro_operaciones.html

3. Pega el contenido y guarda (Ctrl+X, luego Y, luego Enter)

4. Reinicia el servidor:
   touch /var/www/www_egarage_cl_wsgi.py

OPCIÓN 4: Script Python que actualiza solo la sección de navegación

cd /home/atlantareciclajes/apps/egarage/current && \
python3 << 'PYEOF'
import re

file_path = 'templates/taller/cl/es/dashboard/centro_operaciones.html'

# Leer el archivo
with open(file_path, 'r', encoding='utf-8') as f:
    content = f.read()

# Buscar la sección de navegación y agregar el botón de Servicios si no existe
nav_section = r'(<a href="/cl/vehiculos/" class="nav-card">.*?</a>\s*)'

# Verificar si ya existe el botón de Servicios
if '{% country_url \'servicios:servicios_menu\' %}' not in content:
    # Buscar el botón de Vehículos y agregar Servicios después
    pattern = r'(<a href="/cl/vehiculos/" class="nav-card">.*?</a>\s*)'
    replacement = r'\1            <a href="{% country_url \'servicios:servicios_menu\' %}" class="nav-card">\n                <div class="text-3xl mb-2">🔧</div>\n                <div class="font-semibold">Servicios</div>\n                <div class="text-sm text-gray-400">Catálogo de servicios</div>\n            </a>\n\n            '
    content = re.sub(pattern, replacement, content, flags=re.DOTALL)

# Eliminar botón de Configuración duplicado (el que está antes de Otros Servicios)
content = re.sub(
    r'<a href="/cl/es/configuracion/" class="nav-card">.*?</a>\s*',
    '',
    content,
    flags=re.DOTALL
)

# Guardar el archivo
with open(file_path, 'w', encoding='utf-8') as f:
    f.write(content)

print("✅ Archivo actualizado")
PYEOF

touch /var/www/www_egarage_cl_wsgi.py
echo "✅ Servidor reiniciado"
