⚙️  COMANDOS MANUALES (si no usas el script):

# 1. Activar virtual environment
source venv/bin/activate
# O si usas workon:
workon venv_egarage310

# 2. Verificar que Django funciona
python manage.py check --deploy

# 3. Recolectar archivos estáticos
python manage.py collectstatic --noinput --clear
python manage.py collectstatic --noinput

# 4. Verificar archivos subidos
ls -la templates/us/en/onboarding/bienvenida.html
ls -la templates/us/es/onboarding/bienvenida.html
ls -la templates/account/signup.html
