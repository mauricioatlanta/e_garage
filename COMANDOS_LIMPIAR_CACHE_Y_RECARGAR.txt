# Verificar que la vista encuentra el template correcto
python manage.py shell << 'PYTHON'
from taller.vehiculos.views_fbv import _vehicle_template
template = _vehicle_template("crear", "US")
print(f"Template esperado por la vista: {template}")

# Verificar que existe
import os
from django.conf import settings
template_paths = []
for dir in settings.TEMPLATES[0]['DIRS']:
    full_path = os.path.join(dir, template)
    template_paths.append(full_path)
    if os.path.exists(full_path):
        print(f"✓ Template encontrado en: {full_path}")
        print(f"  Tamaño: {os.path.getsize(full_path)} bytes")
    else:
        print(f"✗ Template NO encontrado en: {full_path}")

# También verificar en apps
for app in settings.INSTALLED_APPS:
    if app.startswith('taller'):
        app_path = __import__(app).__path__[0]
        app_template = os.path.join(app_path, 'templates', template)
        if os.path.exists(app_template):
            print(f"✓ Template encontrado en app: {app_template}")
            print(f"  Tamaño: {os.path.getsize(app_template)} bytes")
exit()
