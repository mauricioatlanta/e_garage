  PASO 2: DEPLOYMENT EN SERVIDOR
═══════════════════════════════════════════════════════════════

□ Conectar al servidor:
  
  ssh usuario@tuservidor.com


□ Ir al directorio del proyecto:
  
  cd /ruta/a/e_garage


□ Backup de BD (recomendado):
  
  python manage.py dumpdata > backup_$(date +%Y%m%d).json


□ Pull de cambios:
  
  git pull origin main


□ Activar entorno virtual (si usas):
  
  source venv/bin/activate


□ Verificar modelos:
  
  python manage.py check
  
  Debería mostrar: "System check identified no issues"


□ Cargar ubicaciones:
  
  python manage.py cargar_todas_ubicaciones --skip-existing
  
  Tiempo: 2-5 minutos
  Resultado esperado:
    ✅ 8 países cargados
    ✅ 230 estados
    ✅ 858 ciudades


□ Verificar datos cargados:
  
  python manage.py verificar_ubicaciones
  
  Debería mostrar cobertura completa de 8 países


□ Backfill de clientes (opcional):
  
  # Preview
  python manage.py backfill_addresses --dry-run
  
  # Ejecutar
  python manage.py backfill_addresses
  
  Resultado: Clientes migrados a billing_address


□ Restart del servidor:
  
  # Opción 1: Gunicorn
  sudo systemctl restart gunicorn
  
  # Opción 2: Supervisor
  sudo supervisorctl restart egarage
  
  # Opción 3: Touch wsgi
  touch /ruta/a/wsgi.py
