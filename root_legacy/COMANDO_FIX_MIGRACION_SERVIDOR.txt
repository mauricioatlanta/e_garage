COMANDO PARA EJECUTAR EN EL SERVIDOR:

# Solución rápida - Ejecutar en el servidor:
python manage.py migrate --fake-initial

# Si eso no funciona, verificar estado primero:
python manage.py showmigrations taller

# Luego marcar la migración específica como fake:
python manage.py migrate taller 0001_initial_migration --fake

# Finalmente aplicar migraciones pendientes:
python manage.py migrate

---
EXPLICACIÓN:
- --fake-initial: Marca las migraciones iniciales como aplicadas si las tablas ya existen
- Esto evita que Django intente crear tablas que ya están en la base de datos
- Es seguro usar si las tablas ya existen y tienen la estructura correcta
