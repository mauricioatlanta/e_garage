SOLUCIÓN: CSS APARECIENDO COMO TEXTO EN LA PÁGINA
═══════════════════════════════════════════════════════════════

PROBLEMA:
El CSS aparece como texto visible en la página en lugar de aplicarse.
Esto se debe a que la etiqueta </style> está faltando o mal ubicada.

SOLUCIÓN RÁPIDA:

Ejecuta este comando en el servidor:

cd /home/atlantareciclajes/apps/egarage/current && \
cp templates/public/selector_pais.html templates/public/selector_pais.html.backup && \
python3 << 'PYEOF'
file_path = "templates/public/selector_pais.html"

with open(file_path, 'r', encoding='utf-8') as f:
    content = f.read()

# Verificar si falta </style>
if '</style>' not in content:
    print("⚠️  Falta etiqueta </style>, agregando...")
    # Agregar </style> antes de </head>
    content = content.replace('</head>', '  </style>\n</head>', 1)
    
    with open(file_path, 'w', encoding='utf-8') as f:
        f.write(content)
    print("✅ Etiqueta </style> agregada")
else:
    print("✅ Etiqueta </style> encontrada")
    
    # Verificar que esté en el lugar correcto
    style_pos = content.find('<style>')
    style_close_pos = content.find('</style>')
    head_close_pos = content.find('</head>')
    
    if style_close_pos > head_close_pos:
        print("⚠️  </style> está después de </head>, corrigiendo...")
        # Mover </style> antes de </head>
        content = content.replace('</style>', '', 1)
        content = content.replace('</head>', '  </style>\n</head>', 1)
        
        with open(file_path, 'w', encoding='utf-8') as f:
            f.write(content)
        print("✅ </style> movido al lugar correcto")
    else:
        print("✅ Estructura correcta")

print("✅ Verificación completada")
PYEOF

touch /var/www/www_egarage_cl_wsgi.py && \
echo "✅ Servidor reiniciado"

VERIFICACIÓN:

Para verificar que está correcto:

cd /home/atlantareciclajes/apps/egarage/current && \

grep -n "</head>" templates/public/selector_pais.html
