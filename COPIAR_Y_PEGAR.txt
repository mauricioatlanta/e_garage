█ OPCIÓN 2: PASO A PASO (MANUAL) 🔧
───────────────────────────────────────────────────────────────

▼ PASO 1: Cambiar al directorio del proyecto
───────────────────────────────────────────────────────────────
cd E:\projecto\e_garage
───────────────────────────────────────────────────────────────

▼ PASO 2: Hacer backup
───────────────────────────────────────────────────────────────
Copy-Item ".\templates\taller\common\clientes\lista_clientes.html" ".\backup_$(Get-Date -Format 'yyyyMMdd').html"
───────────────────────────────────────────────────────────────

▼ PASO 3: Probar localmente
───────────────────────────────────────────────────────────────
python manage.py runserver
───────────────────────────────────────────────────────────────
Luego abre: http://localhost:8000/us/clientes/

▼ PASO 4: Subir a Git
───────────────────────────────────────────────────────────────
git add templates/taller/common/clientes/lista_clientes.html
git commit -m "🎨 Rediseño futurista de clientes - Mobile-first"
git push origin main
───────────────────────────────────────────────────────────────


█ COMANDOS PARA EL SERVIDOR (SSH) 🌐
───────────────────────────────────────────────────────────────

▼ Conectar al servidor
───────────────────────────────────────────────────────────────
ssh usuario@tuservidor.com
───────────────────────────────────────────────────────────────

▼ Ir al directorio del proyecto
───────────────────────────────────────────────────────────────
cd /ruta/al/proyecto
───────────────────────────────────────────────────────────────

▼ Hacer pull de los cambios
───────────────────────────────────────────────────────────────
git pull origin main
───────────────────────────────────────────────────────────────

▼ Activar virtualenv
───────────────────────────────────────────────────────────────
source venv/bin/activate
───────────────────────────────────────────────────────────────

▼ Recolectar archivos estáticos
───────────────────────────────────────────────────────────────
python manage.py collectstatic --noinput
───────────────────────────────────────────────────────────────

▼ Reiniciar el servidor
───────────────────────────────────────────────────────────────
sudo systemctl restart gunicorn
───────────────────────────────────────────────────────────────

▼ Verificar estado
───────────────────────────────────────────────────────────────
sudo systemctl status gunicorn
───────────────────────────────────────────────────────────────


█ VERIFICACIÓN RÁPIDA 🔍
───────────────────────────────────────────────────────────────

▼ Buscar clases nuevas en el archivo
───────────────────────────────────────────────────────────────
Select-String -Path ".\templates\taller\common\clientes\lista_clientes.html" -Pattern "btn-futuristic"
───────────────────────────────────────────────────────────────

───────────────────────────────────────────────────────────────

───────────────────────────────────────────────────────────────

▼ Ver diferencias
───────────────────────────────────────────────────────────────
git diff templates/taller/common/clientes/lista_clientes.html
───────────────────────────────────────────────────────────────


█ ROLLBACK (SI ALGO FALLA) 🔄
───────────────────────────────────────────────────────────────

▼ Restaurar desde backup
───────────────────────────────────────────────────────────────
Copy-Item ".\backup_FECHA.html" ".\templates\taller\common\clientes\lista_clientes.html" -Force
───────────────────────────────────────────────────────────────

▼ O con Git (volver al commit anterior)
───────────────────────────────────────────────────────────────
git checkout HEAD~1 templates/taller/common/clientes/lista_clientes.html
git commit -m "Rollback: Revertir rediseño"
git push origin main
───────────────────────────────────────────────────────────────


█ LIMPIAR CACHÉ 🧹

█ SOLUCIÓN RÁPIDA DE PROBLEMAS 🔧
───────────────────────────────────────────────────────────────

Problema: Los estilos no se ven
→ Solución: Ctrl + F5 en el navegador

Problema: Cambios no aparecen en servidor
→ Solución: En servidor ejecutar:
   git pull origin main
   sudo systemctl restart gunicorn

Problema: Error de permisos
→ Solución: En servidor ejecutar:
   sudo chown -R www-data:www-data /ruta/al/proyecto
