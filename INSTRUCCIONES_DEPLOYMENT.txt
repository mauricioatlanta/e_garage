================================================================================
  OPCIÓN 1: DEPLOYMENT AUTOMÁTICO (Recomendado)
================================================================================

EN EL SERVIDOR:

1. Subir archivos al servidor
   - Usar SCP, FTP, Git o método preferido
   - Destino: /var/www/egarage/

2. Configurar .env
   $ cd /var/www/egarage
   $ cp CONFIGURACION_PRODUCCION.env.example .env
   $ nano .env
   
   Editar:
   - DJANGO_SECRET_KEY (generar nueva)
   - DEBUG=False
   - DB_PASSWORD
   - EMAIL_HOST_PASSWORD
   - ALLOWED_HOSTS=egarage.cl,www.egarage.cl

3. Ejecutar script
   $ chmod +x deploy.sh
   $ ./deploy.sh

4. Crear superusuario (solo primera vez)
   $ source venv/bin/activate
   $ python manage.py createsuperuser

5. Verificar
   $ curl https://egarage.cl/
   $ curl https://egarage.cl/pe/signup/

¡LISTO! Sistema actualizado en 30 minutos.

================================================================================
  OPCIÓN 2: DEPLOYMENT MANUAL
================================================================================

1. Backup
   $ python manage.py dumpdata > backup_$(date +%Y%m%d).json

2. Actualizar código
   $ git pull origin main
   # O copiar archivos nuevos

3. Activar virtual environment
   $ source venv/bin/activate

4. Instalar dependencias
   $ pip install -r requirements.txt --upgrade

5. Aplicar migraciones
   $ python manage.py migrate

6. Colectar estáticos
   $ python manage.py collectstatic --noinput

7. Compilar traducciones
   $ python manage.py compilemessages

8. Comandos de inicialización (solo primera vez)
   $ python manage.py cargar_estados_brasil
   $ python manage.py cargar_estados_venezuela
   $ python manage.py cargar_estados_peru
   $ python manage.py seed_tax

9. Reiniciar servicios
   $ sudo systemctl restart gunicorn-egarage
   $ sudo systemctl reload nginx

10. Verificar
    $ curl https://egarage.cl/
