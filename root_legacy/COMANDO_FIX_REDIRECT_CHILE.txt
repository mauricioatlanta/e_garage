COMANDO PARA CORREGIR REDIRECCIÓN DE CHILE
═══════════════════════════════════════════════════════════════

Ejecuta este comando en el servidor:

cd /home/atlantareciclajes/apps/egarage/current && \
cp taller/urls_extra/chile.py taller/urls_extra/chile.py.backup_redirect_$(date +%Y%m%d_%H%M%S) && \
sed -i 's|/cl/egarage/|/cl/|g' taller/urls_extra/chile.py && \
touch /var/www/www_egarage_cl_wsgi.py && \
echo "✅ Redirección corregida y servidor reiniciado"

O con Python:

cd /home/atlantareciclajes/apps/egarage/current && \
cp taller/urls_extra/chile.py taller/urls_extra/chile.py.backup_redirect_$(date +%Y%m%d_%H%M%S) && \
python3 << 'PYEOF'
file_path = "taller/urls_extra/chile.py"

with open(file_path, 'r', encoding='utf-8') as f:
    content = f.read()

if '/cl/egarage/' in content:
    content = content.replace('/cl/egarage/', '/cl/')
    with open(file_path, 'w', encoding='utf-8') as f:
        f.write(content)
    print("✅ Redirección corregida")
else:
    print("✅ Ya está correcto")
PYEOF

touch /var/www/www_egarage_cl_wsgi.py && \
echo "✅ Servidor reiniciado"
