## ⚠️ NOTAS IMPORTANTES

1. **Contraseñas Comunes:**
   - La mayoría de usuarios de prueba usan: `test1234`
   - Administradores usan: `admin123`
   - Usuario principal USA: `TestUSA2025!`

2. **Detección Automática de País:**
   - El sistema detecta el país por la URL (`/cl/` o `/us/`)
   - No es necesario especificar el país al login
   - El usuario será redirigido según su empresa

3. **Suscripciones:**
   - Los usuarios Trial tienen acceso por 30 días
   - Los usuarios Pagados tienen acceso completo
   - Algunos usuarios pueden tener suscripciones vencidas

4. **Verificación:**
   - Si una credencial no funciona, puede que:
     - La contraseña haya sido cambiada
     - La suscripción haya expirado
     - El usuario haya sido desactivado
   - Contactar al administrador para resetear credenciales
