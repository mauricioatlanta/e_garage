## Resumen

- **Total de modelos registrados:** 12
- **Total de URLs base:** 13 (incluyendo la página principal)

## Notas

- Todas las URLs requieren autenticación y permisos de administrador
- Los IDs en las URLs de ejemplo (`{id}`) deben ser reemplazados por el ID real del objeto
- Algunos modelos pueden tener acciones adicionales disponibles desde la lista
- El admin personalizado (`admin_site`) no está disponible en `/admin/`, solo el admin por defecto (`admin.site`)

## URLs de Acciones Comunes

Todas las páginas de lista tienen estas acciones disponibles:
- **Búsqueda:** Parámetro `?q=termino` en la URL
- **Filtros:** Parámetros de filtro según el modelo
- **Ordenamiento:** Parámetro `?o=1` (número de columna)
- **Paginación:** Parámetro `?p=2` (número de página)

Ejemplo:
- `https://www.egarage.cl/admin/taller/documento/?q=factura&o=1&p=2`
